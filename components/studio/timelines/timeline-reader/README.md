# Timeline Reader

The V2 Timeline reader consumes display-ready owner/public projections and never owns persistence or publication authority.

Timeline v2 supports three grouping modes:

- `CHAPTERS`: Timeline-authored chapter sections rendered as independent collapsible accordions. The first authored chapter opens by default and owner browser expansion state is remembered locally per Timeline.
- `ERA`: groups the already-sorted chronology by Lore-owned era labels.
- `NONE`: renders one continuous chronology.

Clickable Lore cards use the original Crestfall Lore interaction language: gold-border emphasis, warmer surface, slight lift, and gold title on hover/focus. Owner-only private/draft Lore navigation remains constrained by the Timeline/Lore ownership-and-attachment route boundary.
