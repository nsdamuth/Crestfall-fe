# Narrator Directives / Advanced Prompting

Portable narrator-owned Advanced Prompting package for the certified
`narrator.creatorDirectives.v1` contract.

The public Binding Shell is:

`components/studio/narrators/advanced-prompting/NarratorDirectivesEditor.jsx`

It preserves the Character Advanced Prompting visual language while using a
Narrator-specific section taxonomy and stricter authority copy.

## Authority rule

Certification grants eligibility only. Narrator Directives are low-authority
presentation preferences and never establish facts, authorize actions, mutate
state, grant knowledge, control the Player Character or Characters, or advance
Story/Scenario state. Story Presentation and explicit Narrator Configuration
remain higher authority.

## Persistence

Create and Edit bind this package to `creation.data.narrator_directives`.
Server save/certification owns the compiled/security result. The View never
persists directly.
