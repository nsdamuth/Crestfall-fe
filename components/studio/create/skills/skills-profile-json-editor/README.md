# Skills Profile JSON Editor

LOOM JSON authoring tool for one complete `skills_profile_contract_v0` object.

The binding shell delegates state and behavior to a ViewModel and renders a portable View. The editor supports JSON copy, formatting, reset from the visual builder, a downloadable Skills-specific AI authoring guide, validation, and complete-object replacement.

Actor-owned mutable state remains forbidden. Validate & Apply updates the open visual builder only; the normal page Save action controls persistence.
