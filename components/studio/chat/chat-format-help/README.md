# Chat Format Help

V2-only local Story Chat help surface for `/format`.

The command is presentation/help only: it does not create a Story message, spend Coins, or invoke the Story runtime. The page ViewModel owns the open/close state and the portable View owns only the formatting-guide presentation.

The guide documents the player-message semantic contract:

- quote-style RP: quoted speech = dialogue, unquoted prose = action, single-asterisk italics = private thought;
- asterisk-action RP: single-asterisk text = action, ordinary text = dialogue, composer Thought mode supplies private thought;
- `>` = written/digital message;
- backticks = targeted telepathy;
- private thoughts are excluded from ordinary character knowledge unless explicit thought-perception authority is granted.
