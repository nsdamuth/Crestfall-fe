# ID REGISTRY

Created 29 Aug 2026 (R5 improvement 5, Home PRD doc pass). One place
listing every ID family in use, so labels stay unique repo-wide. The
rule: a new standing question, ruling, or queue ID family is claimed
here before first use; an ID inside an existing family checks this
file for collisions first. The collision that created this file:
"C2" named both the roadmap's chat composer wave and the Home PRD's
open continue-surface question.
