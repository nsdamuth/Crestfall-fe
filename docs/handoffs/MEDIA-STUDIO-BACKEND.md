2. Served prices. Screen: the Generate button shows count times the per-image cost; today the frontend reads one constant, IMAGE_GENERATION_COIN_COST = 5 (components/studio/image-studio/image-studio-workbench/useImageStudioWorkbenchViewModel.js), the only price table on the frontend. Call: none yet; proposed GET /api/studio/image-generation/pricing returning { imageCoinCost, remixCoinCost, editCoinCost, upscaleCoinCost, video: { per5sAt720p, multiplier1080p } }. Cost: n/a (this is the price source). Until it exists the frontend keeps the constant and this file says so.
3. Coin gate by total cost. Screen: Generate disables when the balance cannot cover count times 5 (RULED 9 Sep 2026). Call: the same job POST. Proposed: the backend refuses a job the balance cannot cover with a structured error { code: "INSUFFICIENT_COINS", required, balance } so the frontend can show the exact shortfall instead of a generic failure. Cost: n/a.
4. Remix stage. Screen: the Remix tab under the mode toggle (body arrives in a later session, note 5): up to six character images plus one location asset or image, each contributing its featured image and prompt details. Call: none yet; proposed POST /api/studio/image-generation/jobs with mode "REMIX", referenceInputs[] of up to six character creation ids or image ids plus one location, prompt with @img1 style mentions resolved server-side to the reference order. Response: the same job shape. Cost: 20 coins flat per run.
5. Video generation. Screen: the Video option in the mode toggle shows Soon and stays off for alpha; the full video UI is note 7 (later session). Call: none yet. Proposed: POST /api/studio/video-generation/jobs with { mode: "TEXT" | "IMAGE", referenceImageId?, prompt, aspectRatio, count, durationSeconds (5 to 30 in 5s steps), quality: "720p" | "1080p", director: [{ fromSecond, toSecond, prompt }] }. Cost rule (frontend constant table until served): 50 coins per 5 seconds at 720p, three times that at 1080p, multiplied by the count (two 10 second videos at 720p is 200).
6. Tooltip component (frontend only, no endpoint). The render style step tooltips and every "Not available yet" hint use the inline InfoTip recipe or a native title until CR-047 lands (docs/CONTRACT-REQUESTS.md). Listed so nobody looks for a backend piece.

Cost: n/a (saving a preset spends no coins).
