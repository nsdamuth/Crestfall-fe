# Media Studio reference screenshots, Brian's notes, 9 Sep 2026

One line per image, the note in full. Where a screenshot shows both apps, Crestfall is on the left and OurDream (OD) on the right. Match OD's flow and selections, then personalize to Crestfall design law.

01 composer (01-composer.png): Composer sidebar. Image / Video toggle at the top with icons and OD's outer pill style. Below it, two stage tabs: Generate and Remix. Edit lives in the image viewer only (see 6). Remove the Player slot; Character covers it. Asset tiles look like OD: icon centered, title centered at the bottom with required or optional under it, no second icon next to the title. When an asset is selected the tile fills with its image and its name centered at the bottom; the eyebrow label goes away. The required Character tile gets a subtle gold glow like OD's pink glow. Prompt field title becomes CUSTOM PROMPT (optional). Count picker sits beside the Generate button like OD: 2, 4, 8, 16, 32, 64, 128, 256. Button reads "Generate" with a coin icon and the cost (count times 5), no wand icon. Remove the coins block from the composer; the balance already shows in the left sidebar.
02 options (02-options.png): Options. No Options dropdown. Key selections show inline: Render style, Camera framing, Wardrobe theme, Aspect ratio. Advanced stays a dropdown; Negative prompt stays as is. Output count leaves this list (it moved beside the button). Render style keeps the slider and the diagonal step names; remove the top-right pill and the two descriptions; keep one short line of context above the slider and add a hover or tap tooltip on each step with its definition.
03 character picker (03-character-picker.png): Character picker. "Select ingredient" eyebrow becomes "Select asset". Custom moves from the bottom to the first card like OD. Add one filter dropdown to the right of the search bar with the character filters that already exist. Standardize every asset picker to this layout (see 4).
04 pickers and custom modals (04-pickers-custom-modals.png): All pickers and custom modals. Custom no longer switches the slot into inline text mode. Custom opens the preset modal. Primary button "Save and use preset", secondary button on the left "Use once". Merge the "Create new preset" card into the Custom card. Remove the bottom note; the top description says everything needed in one concise sentence. Remove the word "fragment" from placeholders. Every field renders as one row until focused, then grows to two rows and keeps growing as you type (the pattern already used in the advanced editor). Make all selection types consistent and tight; the layout should maximize space.
05 remix (05-remix.png): Remix (OD calls it Fusion). Up to six character images (character or player character assets) plus one location asset or image. A selected asset contributes its featured image and its prompt details to the scene. 20 coins.
05a remix prompt mentions (05a-remix-prompt-mentions.png): Inside the Remix prompt box, typing @ opens a picker of the added images so the prompt can reference @img1, @img2 like OD.
05b remix quality target (05b-remix-quality-target.png): A remix Nick made in OD with Crestfall characters, a throne room location, @ references, and a location description. This is the quality target, and the use case: remix, then upscale and crop in the editor to make banners and marketing images for fan pages, static banners, print, and B2B.
06 image viewer (06-image-viewer.png): Image viewer. Restore the thin gold outline and zoom and pan (mouse drag and scroll on desktop, pinch and drag on mobile). Top bar: remove the pencil and the heart; keep the download icon with the size menu. Bottom bar: Edit (opens the editor, no cost on it), Assign (replaces Reassign asset), Share. Remove Generate variant. Upscale is not on this bar; it lives inside the editor. In edit mode the thumbnail strip below the image is hidden; only the top and bottom bars show.
06a editor (06a-editor.png): Editor. When Edit is tapped the bottom bar becomes the toolbar: hand (move), brush with three circle sizes, eraser, crop, undo, redo, close. The prompt field sits below the toolbar with the button "Generate" plus coin icon plus 20. Painting areas, adjusting the crop, or both is one edit run for a flat 20 coins. Crop: a dark overlay outside the crop box, drag the border to resize, and a pixel entry (example 1080 x 1080) that sets the box size. At the top of the editor, under the title, a note shows the image's current size in pixels next to an Upscale button with a coin icon and 10. A tooltip on it explains what upscale is for (a larger version for fine edits, banners, print, and off-site use) and the size it will produce; that size comes from the backend, never a made-up factor. While it runs, the button stays in place with a geometric waiting icon. After it finishes the note shows the new size, the crop box can grow to it, and every download size becomes available. If the entered crop size is larger than the image, the box stops at the image edge and points to the Upscale button.
07 video tab (07-video-tab.png): Video tab. Shows a "Soon" tag and stays off for alpha. Build the UI anyway. Two modes: Text to video (same asset tiles as Image, custom prompt optional) and Image to video (Add image required, custom prompt required). Both modes: aspect ratios 4:5, 5:4, 9:16, 16:9, 1:1; count 1, 2, 4, 8, 16, 32; duration slider 5s to 30s in 5s steps; quality toggle 720p or 1080p; no model, extend, audio, or 4k options. Cost rule: 50 coins per 5 seconds at 720p, three times that at 1080p, multiplied by the count (two 10 second videos at 720p is 200). The button reads "Generate" with the coin icon and that cost, computed from a frontend constant table until the backend serves it; the table and the rule go in the gap file for Nick. Both modes get a "Custom director" button under the custom prompt that opens rows: a seconds field on the left (0 to 5s, 5 to 10s, and so on) and a prompt field on the right, with a plus button that adds the next row.
07a video director inspiration (07a-video-director-inspiration.png): An alpha user's video prompting by seconds on OD. This is the inspiration for the Custom director rows.
